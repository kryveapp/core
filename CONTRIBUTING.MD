# Contributing
Big thanks for helping out on this project! However there are a few rules to make sure everyones on the same page, and to keep the codebase readable.

## Branches
- **never commit to `main`**
- Always make a new branch for every fix or feature added branched off of the latest main

## Opening PR's
- Push your branch and open a PR against main
- Keep the title short and clear
- In the description explain clearly what you changed and why
- Try to keep it to one fix or feature per PR
- Wait for feedback from a teammate before merging and address any issues with follow up commits, dont force push.

## Commit messages
- Short and descriptive, try to keep it under 5-6 words.
- Write as if you're finishing the sentence "This commit will...", for example: `Add password hasing`
- Same as PR's, keep it to one change per PR.

## Contributors License Agreement
- Before you merge your first PR you'll be prompted to go to our CLA, there you will log in with github, to work on Kryve, its mandatory that you accept the CLA.
- We have a CLA in place because it gives everyone a clear idea of who owns the code and protects all parties if there's ever a dispute 

## Naming Conventions
- **Folders**: kebab-case (lowercase and seperated by hyphens)
- **Files**: camelCase (all words first letter capitalization except on the 1st)
- Please stay consistent even for small/one off files/folders!
